# Соната — десктопный музыкальный плеер

Это нативное приложение для ПК (Windows / macOS / Linux), написанное на Electron + React.
Оно открывается как обычное окно программы — не в браузере.

---

## Что внутри

- `electron/` — главный процесс Electron (создаёт окно)
- `src/` — интерфейс плеера (React + Tailwind + shadcn/ui)
- `index.html`, `vite.config.ts`, `package.json` — конфигурация сборки
- 6 демо-треков с обложками (музыка синтезируется прямо в приложении)

---

## Шаг 1. Установите Node.js (если ещё нет)

Скачайте LTS-версию с https://nodejs.org (включает `npm`).
Альтернатива — установить Bun: https://bun.sh (быстрее, команды `bun install` / `bun run dev`).

Проверьте, что установлено (в терминале):
```bash
node --version   # должно вывести v20 или новее
npm --version
```

## Шаг 2. Распакуйте архив

Распакуйте `sonata-desktop.zip` в любую папку, например в `Desktop/sonata`.

## Шаг 3. Установите зависимости

В терминале перейдите в папку и запустите:
```bash
cd путь/к/папке/sonata-desktop
npm install
```
(При первой установке скачивается Electron ~180MB, это может занять пару минут.)

## Шаг 4а. Запустить в режиме разработки (с горячей перезагрузкой)

```bash
npm run dev
```
→ откроется окно плеера «Соната». При изменении кода окно обновляется автоматически.

## Шаг 4б. Собрать готовое приложение (.exe / .dmg / .AppImage)

```bash
npm run dist
```
→ готовый установщик появится в папке `release/`:
- **Windows:** `release/Соната Setup x.x.x.exe`
- **macOS:** `release/Соната-x.x.x.dmg`
- **Linux:** `release/Соната-x.x.x.AppImage`

Готовый файл можно запускать как обычную программу и отправлять друзьям.

---

## Команды

| Команда           | Что делает                                    |
|-------------------|-----------------------------------------------|
| `npm run dev`     | Запуск в режиме разработки (окно + hot reload) |
| `npm run dist`    | Сборка установщика для вашей ОС               |
| `npm run build:renderer` | Только собрать веб-часть (без Electron)  |

## Возможности

- 6 демо-треков с обложками (музыка генерируется офлайн через Web Audio API)
- Загрузка своих аудиофайлов (MP3, FLAC, M4A, OGG) — обложки и теги извлекаются автоматически
- Визуализатор частот, прогресс-бар, перемотка
- Перемешивание (shuffle) и повтор (off / весь список / один трек)
- Регулировка громкости + mute
- Плейлист с обложками, удаление треков
- Тёмная тема, адаптивный интерфейс

---

## Если что-то не работает

- **`npm install` падает с ошибкой Electron:** попробуйте `npm install --legacy-peer-deps` или установите Bun и запустите `bun install`.
- **На Linux не запускается:** добавьте флаг `--no-sandbox` (измените скрипт в `package.json`: `"start": "electron . --no-sandbox"`).
- **macOS блокирует запуск:** Системные настройки → Конфиденциальность и безопасность → «Открыть всё равно».
- **Windows SmartScreen:** «Подробнее» → «Выполнить в любом случае».
