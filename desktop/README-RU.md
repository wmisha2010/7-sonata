# 7-Sonata — десктопная версия для Windows

Нативное приложение для ПК: обычное окно программы, не браузер. Внутри —
полноценное приложение 7-Sonata (актуальная версия со всеми функциями: поиск
MP3mn, видео Rutube с выбором качества, виджет медиасессии и т.д.), вместе со
встроенным локальным сервером — интернет нужен только для онлайн-поиска и
видео, библиотека хранится на самом ПК.

---

## Что понадобится

Только **Node.js LTS** (v20 или новее): https://nodejs.org
Проверка в командной строке:

```bat
node --version
```

---

## Способ 1. Собрать из архива с релиза (без git)

На странице релиза https://github.com/wmisha2010/7-sonata/releases скачай
файл **`7-sonata-desktop-<версия>-src.zip`**, распакуй его в отдельную папку
(правой кнопкой → «Извлечь всё...»), открой командную строку в этой папке и
выполни шаги 2–3 ниже (установка зависимостей и сборка).

## Способ 2. Сборка .exe своими руками (командная строка)

### Шаг 1. Скачать проект

```bat
git clone https://github.com/wmisha2010/7-sonata.git
cd 7-sonata
```

(если проект уже склонирован раньше — просто сделай `git pull` в папке проекта)

### Шаг 2. Установить зависимости (один раз)

```bat
npm install
```

### Шаг 3. Собрать Windows-версию (одной командой)

```bat
npm run desktop:win
```

Первая сборка скачивает Electron (~110 МБ) и инструменты сборки — подожди
несколько минут. Готовые файлы появятся в папке **`desktop\release\`**:

| Файл | Что это |
|---|---|
| `7-Sonata-1.8.3-Setup.exe` | установщик (ярлык на рабочем столе, меню «Пуск») |
| `7-Sonata-1.8.3-portable.exe` | портативная версия — один файл, без установки |

---

## Запуск

- **Setup.exe** — запусти, выбери папку установки → приложение появится
  в меню «Пуск» и на рабочем столе (ярлык «7-Sonata»).
- **portable.exe** — просто запусти файл, установка не нужна.

> ⚠️ Windows SmartScreen может предупредить о неизвестном издателе — это
> нормально для самособранной программы без платной подписи кода.
> Нажми «Подробнее» → «Выполнить в любом случае».

---

## Как это устроено (для любопытных)

- Приложение = Electron-окно + встроенный production-сервер Next.js
  (лежит в `resources/server` внутри установленной программы).
- Сервер поднимается на свободном порту `127.0.0.1` при запуске и закрывается
  вместе с окном — снаружи приложение никуда не светится.
- Логи сервера: `%APPDATA%\7-Sonata\sonata-server.log`.

### Сборка вручную, по шагам (если хочется без скрипта)

```bat
npm run build              :: сборка Next.js (standalone)
cd desktop
npm install                :: один раз
npm run stage              :: скопировать сервер в staged/
npx electron-builder --win :: собрать exe в release/
```

### Собрать под другую ОС

```bat
npm run dist:linux    :: AppImage (из-под Linux)
npm run dist:mac      :: dmg (из-под macOS)
```
